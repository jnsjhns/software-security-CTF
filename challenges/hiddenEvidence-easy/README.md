# Hidden Evidence

**Category:** Forensics  
**Difficulty:** Easy  
**Flag Format:** `CTF{...}`

## Scenario

During an internal security investigation, an image was recovered from an employee's laptop.

The image appears to contain ordinary case information. 
However, investigators suspect that it may reveal more than what is immediately visible.

## Your Mission

Analyze the provided `evidence.png` and recover the hidden flag.

Good luck!
