# Hints: Apache Path Traversal

1. **Hint 1:** Pay attention to the portal's migration notice and read the
   included Apache configuration.
2. **Hint 2:** Compare how the configuration maps URL paths to directories
   with the rules that allow access to those directories.
3. **Hint 3:** In the local challenge, investigate how Apache normalizes paths
   and which resource outside the DocumentRoot should be reachable.
