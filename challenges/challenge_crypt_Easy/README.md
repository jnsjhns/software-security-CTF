# Nova Robotics – Lost Wiki Password

## Story

Nova Robotics is a fictional startup that has lost the password to its internal wiki.

An intern claims that he saved a reminder in a note, using a secret cipher he invented himself.

Unfortunately, the only remaining file is `note.enc`.

The note seems unreadable, but maybe it contains more information than it appears...

Can you recover the hidden message and find the flag?

## Challenge Information

- **Category:** Cryptography
- **Difficulty:** Easy
- **File provided:** `note.enc`
- **Flag format:** `ISEP{...}`

## Objective

Analyze the provided file, recover the original message, and find the flag.

You may use tools such as CyberChef to analyze the file.

Good luck!
